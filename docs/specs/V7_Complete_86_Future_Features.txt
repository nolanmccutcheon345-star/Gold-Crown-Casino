FUT001: Run it twice
Required behavior: Split only eligible settled pot per approved room/consenting participants, one deck and two
independent remaining runouts; rake once; main/sidepot eligibility; UI prompt
Dependencies: R1 settled all-in engine
Priority: HIGH | Status: DEFERRED_NOT_IMPLEMENTED
Constraints: Requires unanimous applicable consent; never increase expected equity automatically

Required behavior: N independent runouts with correct deck exhaustion, fractional chips and per-pot awards; variant
room choice
Dependencies: Run it twice
Priority: MED | Status: DEFERRED_NOT_IMPLEMENTED
Constraints: No universal venue rule
FUT003: Side-pot-only run-it-twice
Required behavior: Only consenting eligible sidepot players can split that pot while main pot may run once
Dependencies: Run it twice; side pot oracle
Priority: MED | Status: DEFERRED_NOT_IMPLEMENTED
Constraints: Explicit room-specific eligibility

Required behavior: Each dealt-in participant posts configured ante, skip preflop betting, go to flop; pot and rake rule
tested

FUT005: Double-board NLHE bomb pots
Required behavior: Two independent boards and split awards, sidepots per eligible shares and odd chips tested
