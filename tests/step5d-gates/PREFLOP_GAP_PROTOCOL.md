# Current-policy F01 / R03 evidence protocol

This protocol is recorded before the new fixtures run. It adds current-policy assertions missing from earlier report associations; it does not change poker policy or original acceptance wording.

F01 compares TAG first-in probability mass at seat 3 (UTG) and button 0 in six through ten occupied seats, at 20, 100 and 250 BB, with three frozen identities `0x5df001`, `0x5df102`, `0x5df203`. Earlier seats legally fold before the button node. The independent test enumerator supplies all 169 classes weighted by all 1,326 physical combinations. Report actual opening-raise and voluntary-entry weighted combinations and differences. Required direction is button greater than UTG for both measures; no stochastic frequency quota or newly tuned threshold is introduced. Heads-up and three-handed games have no distinct UTG comparison and are not relabeled to invent one. Exact observed effect sizes must be reviewed for the original materiality wording.

R03 compares the same QJs and 97s classes at cutoff and button in actual six-seat unopened, limped, facing-open and facing-3bet nodes. Frozen TAG identity `0x5d0301`, 100 BB, blinds 100/200 cents. Earlier public actions are legal and held fixed within each declared context. The expected node must match the public sequence; same-class distributions must differ across nodes and at least one corresponding node must differ by position. The unchanged input class, opportunity state, full distributions and sampled legal action sizes are recorded. No universal action ranking between context families is imposed.

All claims are synthetic functional behavior. These checks do not supply human frequency calibration, independent optimal strategy, or a complete full-hand performance benchmark.
